# Ziki Agent Approval Experience — independent prototype

An interactive, standalone HTML/CSS/JavaScript prototype for HNG15 Task 1: improving human–AI agent interaction in the agent-pairing/approval workflow.

## Try it

Open `index.html` in a browser and choose **Improved experience**. Enter `ZIKI-2048`, review agent identity/permissions, acknowledge them, and confirm approval. You can also test empty/invalid codes and the **Simplified before** tab.

## Why this design

The proposal helps humans make informed approval decisions through clear context, permission explanations, validation, explicit acknowledgement, and status feedback. The baseline view is *illustrative*, not a claim about Ziki's exact existing features.

## Deployment

Deploy the directory as a static site to Vercel (Framework Preset: Other; no build command; output directory left blank) or drag the directory to Netlify Drop. No package installation, backend, credentials, or API calls required.

## Evidence / limitations

Use screen recording showing invalid code feedback, valid pairing, identity/permission review, acknowledgement, and demo confirmation. This prototype is **not** part of production Ziki and does not approve real agents. Team approval and actual Ziki source integration would be required for any production change.
